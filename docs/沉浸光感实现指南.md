# 沉浸光感（ImmersiveMaterial）实现指南

> 2026-09-23/24 播放器 + 私信全套真机调优总结。配方均经真机（7.0.0.107 / API 26）验证；
> 6.1（API 24）兼容注意事项见文末。

---

## 一、两套材质体系（别混用）

| | uiMaterial.ImmersiveMaterial | hdsMaterial.MaterialLevel |
|---|---|---|
| 挂载方式 | 传给弹层的 `systemMaterial` 参数 | HdsTabs/HdsNavigation 的 `systemMaterialEffect` |
| 档位 | `ImmersiveStyle`：ULTRA_THIN / THIN / REGULAR / THICK / ULTRA_THICK | `MaterialLevel`：EXQUISITE / GENTLE / SMOOTH / ADAPTIVE |
| 可用表面 | **弹层作用域**：bindSheet / bindPopup / openCustomDialog | HdsTabs `barFloatingStyle`、HdsNavigation `titleBar.style`（仅此两处） |
| 附加参数 | interactive（按压光）、lightEffect（光效层）、materialColor（钉色） | 无按压光/光效参数（天然静态） |

⚠️ hdsMaterial 的档位（ADAPTIVE 等）**传不进 popup**；uiMaterial 也别塞进 systemMaterialEffect。两套各走各的。

⚠️ 内容区（页面普通布局里）**直接挂 systemMaterial 不渲染**——真材质只有三条路：
弹层（bindSheet / bindPopup）、HdsTabs barFloatingStyle（把内容塞进 tabBar）、HdsNavigation titleBar。

---

## 二、各处实现配方（本工程现状）

### 1. 播放器手势提示胶囊（VideoControls）
- 通道：`bindPopup` + `CustomPopupOptions.systemMaterial`（**弹层作用域**，26.0.0 起支持）
- 材质：`pillMaterial()` = REGULAR + `interactive: true` + `materialColor: '#66000000'`
  - 40% 黑固定染色层：钉住深浅色切换（见下文"钉色"），且用户已验收这个透亮观感
- 圆角：`radius`（弹层画的，跟内容无关）；`colorMode: FOLLOW_TARGET`
- 锚点：常驻 1vp 透明点（popup 显隐必须状态驱动，锚点不能 if 挂载）；`mask:false` 不挡手势
- ⚠️ API 24 分通道：`hintUsePopup = MaterialUtil.available()`，老机连 bindPopup 分支都不进（26.0.0 弹层新字段会打挂整棵子树）

### 2. 播放器 7 个半模态面板（bindSheet）
- 材质：`sheetMaterial()` = **THICK + `interactive: false` + `lightEffect: null`**（静态玻璃、无光）
- ⚠️ 面板内容根背景必须全透明（材质层在 backgroundColor 之下）；不叠 backgroundBlurStyle

### 3. 文本工具弹窗（TextSelectionDialog）
- `openCustomDialog` + `backgroundColor: Transparent` + `systemMaterial`（sheetMaterial 同款）
- 内容根按有无材质双分支：有材质→透明根；无→原降级底

### 4. 动态页 UP 面板 / 悬浮按钮 / 搜索框
- 通道：`HdsTabs` + `barFloatingStyle.systemMaterialEffect`（IMMERSIVE + EXQUISITE/ADAPTIVE）
- ⚠️ **bar 形状是系统自绘胶囊（两端半圆）**，`HdsTabsFloatingStyle` 无任何形状/圆角参数——要圆角矩形就别走这条
- ⚠️ `gradientMask` 必须显式 `{ maskColor: Color.Transparent }`（省略=黑色遮罩）
- ⚠️ `barWidth` 必须传**数值**（'100%' 会溢出屏幕）；bar 内容高度写 `'100%'`（系统容器自带 ~3vp inset，写死会溢出）

### 5. 聊天输入胶囊（WhisperInputBar）
- HdsTabs barFloatingStyle（IMMERSIVE + ADAPTIVE），宽度 = `barW()`：
  `capsuleW - buttonSpaceVp - (buttonSpaceVp > 0 ? 8 : 0)`
  - capsuleW 由胶囊行 `onAreaChange` 测量（0.5vp 死区防循环）
  - **8vp 间距只在发送按钮可见时扣**——恒扣会让按钮隐藏时右边距 16+8 ≠ 左边距 16
- 行上**不能挂 layoutWeight(1)**：父容器高度自适应时 weight 让行高失控（实测撑到 1952px，胶囊"跑到屏幕中间"）

### 6. 表情面板（最终形态，2026-09-24 定稿）
- bindPopup + `emoteMaterial()`（THICK 静态玻璃，**独立实例**）+ `radius: 22`（圆角矩形）
- `placement: Top`（悬浮输入框上方）+ `offset: { x: (barW-capsuleW)/2, y: -8 }`
- builder 只画内容：宽 = barW（与胶囊对齐）、高 300、clip + borderRadius 22、**不画底色**、根节点 `padding {left:8, right:8}`（防表情贴边出框）
- API 24 兜底：页内渲染旧路径（emoteH 高度动画），与新通道按 `emoteUsePopup` 分流

### 7. ❌ 全局确认对话框（失败案例，已回退）
- 曾用 openCustomDialog 自建沉浸对话框替换 25 处 AlertDialog/showDialog → **真机整个不渲染**
- 独立材质实例也救不回来，已全部还原系统组件并删除工具类
- **教训：提示类确认框保持系统 showDialog/AlertDialog；批量替换必须先真机回归 1 处再铺开**

### 8. UP 主空间页分段按钮（UpSpacePage，2026-09-25 定稿）
- 需求：内容区**常驻**的两个独立胶囊（投稿/动态 + 排序，分居两端、中间留白）要真沉浸光感。
- 通道：**每个胶囊各包一个 HdsTabs 浮动条**——官方 SegmentButton（透明底）装进 tabBar，
  玻璃由系统自绘（两端半圆胶囊），`barFloatingStyle.systemMaterialEffect`（IMMERSIVE + ADAPTIVE）。
  浮动条本身就是合法材质表面，内容区可用（DynamicsPage 悬浮钮 / HdsMiniBarButton 同源，真机已验证；
  YunShangSJ `ServerPage.segControl` 同款写法）。
- 代码骨架：

```typescript
HdsTabs() {
  TabContent()
    .tabBar(this.segContent())   // Stack { SegmentButton 透明底 .width('100%').height('100%') }
}
.barWidth(this.tabW)             // ⭐ 必须数值（本页胶囊宽本就是计算值，免实测）
.barHeight(44)
.height(44)                      // ⭐ 无界滚动上下文（List/Scroll）里必须钉死宽高，否则布局爆炸
.width(this.tabW)
.barOverlap(true)
.barPosition(BarPosition.End)
.barFloatingStyle({
  gradientMask: { maskColor: Color.Transparent },   // ⭐ 省略 = 黑色遮罩（红线 13）
  barBottomMargin: 0,
  systemMaterialEffect: {
    materialType: hdsMaterial.MaterialType.IMMERSIVE,
    materialLevel: hdsMaterial.MaterialLevel.ADAPTIVE   // 深浅色/背后内容自适应
  }
})
.clip(false)
```

- ⚠️ "两个分居两端的胶囊"= **每个胶囊各一个 HdsTabs**；不要把整行塞进一个 bar——单 bar 是一整条系统胶囊，中间空隙画不出来（"HdsTabs 通道做不了"的判断只对"整行一条"成立）。
- ⚠️ 材质是系统画的 ⇒ 卡片样式染色层盖不上：透明/纯色卡片风格、圆角滑块对它**无效是预期**；深浅色由 ADAPTIVE 自适应，App 侧不再叠底色/模糊。
- ⚠️ tabBar 内容根全透明（options 的 backgroundColor: Color.Transparent），选中滑块与主题色由官方自绘；bar 内内容高度写 `'100%'`（§5，系统自带 ~3vp inset）。
- 滚动/吸顶兼容：胶囊行作为 ListItem 随内容滚动，材质跟随自身节点、无弹层锚点跟随问题；吸顶替身同构（占位同高 + 交换点像素级对位照旧）。胶囊宽若为固定设计值（竖屏 124/176 紧凑定宽），barWidth 直接吃现成数值。

## 三、去光只留玻璃（本问核心）

光有两层，都要关：

```typescript
new uiMaterial.ImmersiveMaterial({
  style: uiMaterial.ImmersiveStyle.THICK,   // 玻璃厚度档位
  interactive: false,                        // ① 关按压光（按压时的光斑/形变）
  lightEffect: null                          // ② 关光效层（彻底关）
})
```

- `interactive: false` 之后真机**仍有点按光**——光源在 lightEffect 层；
  ⚠️ `lightEffect: { color: undefined }` 是"用默认光色"不是关，必须传 **`null`**（官方签名允许）
- **HdsTabs barFloatingStyle 通道天然无光**（没有 interactive/lightEffect 参数），无需处理
- 保留光的例外：提示胶囊 `pillMaterial` 用 `interactive: true`（用户验收的观感，勿联动改）
- 当前实例分工（MaterialUtil 按表面分工厂，**每表面一个实例，不共用**）：
  - `sheetMaterial()`：bindSheet 面板 + 文本工具弹窗（THICK 静态玻璃）
  - `pillMaterial()`：播放器提示胶囊（REGULAR + 40% 黑 + 有光）
  - `emoteMaterial()`：表情面板（THICK 静态玻璃）

## 四、关键注意事项（踩坑实录）

### 深浅色钉色
- 材质底色由系统主题驱动；popup 的 `colorMode`（FOLLOW_SYSTEM / FOLLOW_TARGET）**实测都拦不住变色**
- 唯一旋钮 = `materialColor` 固定染色层：**必须带透明度**（不透明会把玻璃整层盖死）；40% 黑 `#66000000` 定稿（80→60→40 逐级降出来的）

### popup 行为语义
- `offset` 是**屏幕坐标**（+y 恒向下）：Top 方向拉开间距用**负值**；Bottom 方向正值远离
- **放置方向在显示瞬间锁死**：空间不足会翻转，翻转决定不随锚点移动重算（试图"先让位再显示"的竞态方案全败）→ 悬浮面板选"上方"这种空间充裕的方向最稳
- 弹层默认以锚点**水平居中**：宽度 ≠ 锚点宽时用 `offset.x = (弹层宽 - 锚点宽)/2` 保持左缘对齐
- mask:false + autoCancel:false 时收起全靠状态开关；弹层自带出入场动画（无需自己做高度动画）

### 内容约束
- **Grid/List 自身的 padding 对横向滚动内容不生效**（内容会滑到容器边缘）→ 安全边距加在**外层容器**
- 挂材质的表面：内容根全透明、不叠磨砂，否则盖死玻璃

### API 24（HarmonyOS 6.1）兼容
- 26.0.0 弹层新字段（systemMaterial / colorMode 等）在老机会**打挂整棵子树**——必须
  `MaterialUtil.available()` 探测通过后**动态补挂**（`opts.systemMaterial = ...` 属性赋值），
  不能写死在 options 字面量里
- `deviceInfo.apiAvailable` 本身 @since 26.0.0（老机抛 TypeError，MaterialUtil 里已 try/catch）
- bindSheet 传 undefined 材质已实证无害
- **所有弹层新代码上线前必须在 6.1 老机回归**

### 调试手法
- 布局几何：`hdc shell uitest dumpLayout -p /data/local/tmp/x.json` + `hdc file recv`，转 JSON 按 bounds 分析（物理像素，本机 2.545 px/vp）
- 可全自动导航自测（uiInput click），不用来回麻烦人
- 材质创建失败/能力探测：看 Logger 的 `[MaterialUtil]` 日志

## 五、速查：我要做 X，用哪条路？

| 需求 | 通道 | 材质配方 |
|---|---|---|
| 底部半模态面板 | bindSheet | sheetMaterial（THICK 静态玻璃） |
| 锚点悬浮提示（圆角矩形） | bindPopup + radius | pillMaterial（REGULAR + 40% 黑，有光） |
| 内容区胶囊形悬浮件 | HdsTabs barFloatingStyle | IMMERSIVE + ADAPTIVE/EXQUISITE |
| 内容区**分段按钮/定宽胶囊**（真材质） | 每胶囊包一个 HdsTabs 浮动条（钉死数值宽高，§二.8） | IMMERSIVE + ADAPTIVE |
| 内容区圆角矩形大面板 | bindPopup（HdsTabs 做不了圆角矩形） | 独立实例静态玻璃 |
| 确认对话框 | 系统 showDialog / AlertDialog | ❌ 不做沉浸（openCustomDialog 路线已证伪） |
| 去光只留玻璃 | — | `interactive:false` + `lightEffect:null` |
